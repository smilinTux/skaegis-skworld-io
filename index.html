What it is

Continuous vulnerability intelligence for your whole fleet, from one self-hosted service. Detection to remediation as a closed loop, with no SaaS in the middle and no inventory leaving your network.

Whole-fleet visibility

One detection fabric across Linux, Windows and macOS, so a CVE on a laptop is not a blind spot next to the server rack.

Continuous, not scheduled

New advisories are matched against what is actually installed on each host as they land, instead of waiting for the next quarterly scan.

Ranked, not just listed

Findings are ordered by exploitability and exposure, so the short list at the top is the one worth your morning.

Yours to host

Runs on your infrastructure behind your own single sign-on. Findings and host inventory stay inside your walls.

The three share one loop. sksec reduces what can reach you, skaegis finds what is weak on your side, skpatch fixes it. You can adopt skaegis on its own.

The closed loop

A finding is not done when it is reported. It is done when a re-scan shows it gone.

Detect

Agents report installed software on every host. New CVE data is matched against it continuously.

Triage

Findings are ranked by exploitability and exposure, using a model that runs locally, so context stays in-house.

Remediate

The fix goes into your patch pipeline: package updates for hosts, pull requests for dependencies and images.

Verify

skaegis re-scans. When the CVE no longer appears, the change is closed. If it does, it stays open.

FAQ

Does any data leave my network?

No. skaegis is self-hosted. Host inventory, findings and triage stay on your infrastructure. It pulls public vulnerability feeds in, and sends nothing of yours out.

Which operating systems are covered?

Linux, Windows and macOS, using a lightweight agent on each host.

Will it fix things automatically?

Only at the Guard tier and above, and through your own patch pipeline, so your review and change process still applies. Watch only detects and reports.

Does it find every vulnerability?

No tool does. It detects known, published CVEs against software it can see on enrolled hosts. It does not find unknown flaws, and a host without an agent is not covered. It reduces exposure, it does not make a system impossible to breach.

Is it built on open source?

Yes. The detection engine is an established open-source platform, run unmodified from pinned images and packaged with SSO, ingress and backups as one product.

Do I need sksec and skpatch too?

No. skaegis stands alone. Together the three cover defend, detect and remediate.

When can I use it?

It is in design and early build. Watch this site and the repository for updates.

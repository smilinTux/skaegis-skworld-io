# Contributing to skaegis-skworld-io

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are licensed GPLv3.

## Workflow
1. Branch from `main` (never commit to `main`): `git switch -c fix/<topic>`.
2. Edit `index.html`. Check at phone width and desktop width.
3. Run the checks in [SOP.md](./SOP.md) section 4, including the dash check and the docs gate.
4. Add a `CHANGELOG.md` entry for user-visible changes.
5. Open a pull request.

## Commits
Imperative subject, short body. If an AI agent did the work, add a `Co-Authored-By` trailer naming that agent; otherwise leave it out. Do not claim co-authorship you cannot evidence.

## Content rules
- No em dashes or en dashes anywhere. Use commas, parentheses, colons or hyphens.
- Honest claims only. No "unhackable", "100% secure", "quantum-proof". Say what the product does and where it stops.
- Keep plans labelled as plans.
